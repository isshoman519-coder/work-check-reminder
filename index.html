갤럭시 · Android 진동 확인

진동은 휴대폰 알림 설정에 따라 달라집니다. 아래 테스트로 직접 확인해 주세요.

알림은 뜨는데 진동이 없을 때
  1. 받은 테스트 알림을 길게 누르고 설정을 엽니다. 표시되는 앱(Chrome 또는 근무확인 알리미)의 해당 알림을 확인하세요.
  2. 「소리 및 진동 허용」을 선택하고, 해당 알림 카테고리의 「진동」을 켭니다.
  3. 카테고리가 안 보이면 설정 → 알림 → 고급 설정 → 「앱별 알림 카테고리 관리」를 켭니다. 기기에 따라 메뉴 이름이 다릅니다.
  4. 설정 → 소리 및 진동 → 진동 세기에서 알림 진동을 올리고, 방해 금지·수면 모드도 확인합니다.
  5. 위 테스트가 울리면 「테스트 알림 보내기」로 서버 푸시도 확인합니다. 마지막으로 폰 앱을 닫고 실제 예약 알림을 확인하세요.

웹앱은 휴대폰의 무음·진동 설정을 강제로 바꿀 수 없습니다. 「앱 화면에서 진동 확인」은 화면을 보고 버튼을 누를 때의 테스트이며, 앱을 닫은 뒤 푸시 진동을 보장하지 않습니다.
